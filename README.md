# Последний рассол

Исходный проект сюжетной RPG на Godot 4. Герой — Валерий Похмельцев, город Гниловск, 1996 год.

Текущая базовая сборка: v0.3.1. Диалоги полностью офлайн, без LLM и без голосовой системы.

В репозиторий будут добавлены сцены, GDScript, сценарные JSON и инструменты проверки. Сборки необходимо проверять в редакторе Godot 4.
