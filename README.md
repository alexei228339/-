# Последний рассол

Оригинальная офлайн-RPG о Гниловске 1996 года. Герой — Валерий Похмельцев.

## Что сейчас есть в GitHub

**Ранняя текстовая демонстрация**, запускаемая в Godot 4: сцена `main.tscn`, скрипт `scripts/main.gd`, переходы между квартирой/подъездом/двором через варианты ответов, персонажи, несколько сюжетных улик, кнопки сохранения и загрузки.

## Как запустить

1. Скачайте репозиторий как ZIP на GitHub (Code → Download ZIP).
2. Распакуйте и откройте `project.godot` в Godot 4.
3. Нажмите F5.

## Ограничения

Это **не перенесённая v0.3.1 и не изометрическая сборка**. Исходные GDScript, диалоги и игровые карты v0.3.1 пока не перенесены полностью. Текущая демонстрация содержит заранее заданные ответы, не использует сеть, нейросети или голос. Проверка запуска в редакторе Godot ещё не проведена.
